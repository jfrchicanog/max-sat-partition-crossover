PX-TT-Open-WBO-Inc: Adding Partition Crossover to a MaxSAT solver

This is a modified version of TT-Open-WBO-Inc to include Partition Crossover (PX). The original TT-Open-WBO-Inc algorithm is by Alexander Nadel. The current variant has been implemented by Patricia Da-Concepción and Francisco Chicano.

The license is MIT. See code/LICENSE for further details.

To compile, make sure that your g++ version is at least 10.1 and run:

```
cd code
make rs
```
